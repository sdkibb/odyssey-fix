2019 Honda Odyssey Screen Fix: Options

The dead centre screen on a 2018-2020 Odyssey is a well-documented problem. His VIN shows the screen-related recalls are already done, so start with the free resets and software update. If the part really has failed, a used 39710-THR-307 display plus a DIY swap costs a fraction of Honda's roughly $3,000 quote.

Bottom line

The recall route won't fix this screen. His VIN shows the screen-related recalls, including the MOST network cable recall (P56/P57), are already completed. Skip the recall step: try the free resets and the software update first, then a used 39710-THR-307 screen.

If the screen is still dead after the resets and update, the cheapest good fix is usually a used, tested OEM part with the exact same part number. For his EX-L that's display 39710-THR-307, which runs about US$177-300 used. A control unit runs about US$250-760. You can swap it yourself in an afternoon.

His van does have one open recall, for unintended side and side curtain airbag deployment. It's free at any Honda dealer. Book it, and ask them to look at the screen while it's in.

Is this a known issue?

Yes. Honda has issued a recall, a warranty extension, software updates and several service bulletins for 2018-2020 Odyssey infotainment problems. There was also a US class action over the same symptoms.

Honda's own technician guide says a MOST network failure “will cause a no-response condition from the infotainment system with the center display unit going blank”. It also says that if any audio functions still work, the blank screen “may just be a display issue and not a network failure.”

Try these first

These steps are free or nearly free, so try them in this order.

  1. Recall check by VIN (done)Checked Oct 22 2026: the screen-related recalls, including P56/P57, are already completed on his VIN, so skip this step. See VIN results above.
  2. Soft rebootWith the ignition ON, hold the VOL/power knob for about 10 seconds until the screen restarts. Consumer Reports says to hold it 5 seconds and pick reboot if a menu appears.
  3. Door trickTurn the van off, open and close the driver's door, wait, then restart. This forces the system to power down fully.
  4. 12V battery resetWith everything off, disconnect the negative terminal (10 mm) for 5-10 minutes, then reconnect. You may lose presets and the clock.
  5. Fuse checkFind the audio/display fuse using the diagram in the owner's manual. Pull it, check it, reseat or replace it with the same amp rating.
  6. Software updateIf the screen comes back even briefly, go to Home, then System Updates, then via Wireless or via USB (usb.honda.com). The 2019 Odyssey's latest listed version is B.1.4.4.
  7. Free self-diagnosisOn the driver's gauge screen, go to Settings, then hold HANG-UP and then ENTER on the steering wheel. This opens Honda's MOST network test, which shows if a module has dropped off the network.

Which part has failed?

The screen has two main parts, and they're sold separately. Buying the wrong one is the most common waste of money.

Centre display (the screen)
Part 39710-THR-307 for EX, EX-L and Touring (replaces -306, -A11, -A12). Part 39710-THR-315 for Elite (replaces -305).
Infotainment control unit (the brain)
Part 39540-THR-xxx. The suffix depends on trim and options, e.g. -A57 for EX-L Navi/RES and -A77 for Touring. Used EX units are listed as -A12.
Display cable
LVDS cord 39725-THR-A00, US$56.47 at HondaPartsNow or CA$81.50 at Classic Honda.
Base LX
Uses a different display and isn't interchangeable with the 8-inch EX-and-up screen.
  • Sound still works but the screen is black: the display or its cable is the likely suspect.
  • No sound, no screen and no backup camera: suspect the MOST network (the recall) or the control unit first.
  • The screen reboots over and over or freezes: start with software and the recall.

DIY replacement plan

Difficulty
Moderate. It's all trim panels and bolts, but there are a lot of them.
Time
Honda's flat rate for a similar dash job is 2.0 hours for a trained tech. Budget half a day for a first attempt (estimate).
Tools
Plastic trim tools, Phillips screwdriver, 8 mm and 10 mm sockets with an extension, masking tape and a marker for labels, a tray for screws
Radio code
Honda's install steps for the control unit have no radio-code entry. They say to run System Links in diagnostic mode afterwards.
Programming
A used display of the same part number is the simplest swap. A used control unit may need VIN programming at a dealer; sellers disagree on whether it's required.
  1. Recall and trim (confirmed)Recall P56/P57 is done and his van is an EX-L, so the matching display is 39710-THR-307.
  2. DiagnoseDoes sound still work? Does the backup camera show? Run the MOST test from Try these first to decide between the display and the control unit.
  3. Disconnect the 12V batteryNegative terminal, 10 mm.
  4. Remove the trimIn service manual order: volume knob, upper dash trim, driver inner trim, passenger trim, then the Blu-ray player, CD player or centre pocket.
  5. Release the unitRemove the two upper bolts and loosen the two lower 8 mm bolts behind the pocket, then slide out the centre display assembly.
  6. Read the part numbersPhotograph the labels on the display and the control unit, then order exact matches. You can do this on a first teardown before buying anything.
  7. Label every connectorDon't swap the red and green FAKRA plugs, and don't pull the unit while they're still attached.
  8. Swap and reassembleFit the replacement, secure all connectors, then reinstall everything in reverse order.
  9. TestHold the VOL/power knob, Day/Night and HOME together for Dealer Diagnostics, run System Links, then update the software.

Why DIY

  • A used display costs a fraction of a new one
  • No labour charge
  • Removal is well documented in videos and the service manual

Risks

  • The wrong part number or trim means it won't work
  • A control unit may still need dealer programming
  • Trim clips can break, and the MOST connectors are delicate
  • Used parts carry only the seller's warranty
